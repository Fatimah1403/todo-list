# Todo List

A simple todo list app built with React and Vite as part of the Code the Dream React course (Week 1). It renders a title and an unordered list of todo items.

## Installation

1. Clone the repo:
   ```
   git clone https://github.com/Fatimah1403/todo-list.git
   ```
2. Move into the project directory:
   ```
   cd todo-list
   ```
3. Install dependencies:
   ```
   npm install
   ```

## Running the Development Server

Start the Vite dev server:
```
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173) in your browser to view the app.
